# DeepParser 产品资料（售前版）

- DeepParser 是上海聚托（JOTO）自研的 AI 文档解析引擎，面向企业级非结构化文档处理

<!-- page 2 -->
# 定位与问题

- 企业 80% 的数据沉淀在 PDF、扫描件、PPT 等非结构化文档中，传统 OCR 无法还原文档结构

<!-- page 3 -->
# 核心指标

- DeepParser 对中文复杂版式文档的解析准确率达到 98.2%，覆盖表格、公式、图表与跨页段落
- 单页平均解析耗时 0.8 秒，百页文档整体解析在 90 秒内完成

<!-- page 4 -->
# 表格解析能力

- 支持无线表、合并单元格、跨页表格的结构化还原，表格还原准确率 97.5%
- 解析结果直接输出 Markdown、JSON、CSV 三种格式，可直接对接下游系统

<!-- page 5 -->
# 公式与图表

- 内置 LaTeX 公式识别，支持印刷体与手写体公式，识别准确率 96.8%
- 支持将文档内嵌图表转换为结构化数据点，供二次分析使用

<!-- page 6 -->
# 版面分析

- 自研版面分析模型可识别 27 种文档元素类型，包括页眉页脚、脚注、批注与水印
- 支持双栏、三栏等复杂多栏排版的阅读顺序还原

<!-- page 7 -->
# 部署方式

- 提供私有化部署与 SaaS 两种形态，私有化版本支持纯内网环境离线运行
- SaaS 版本开箱即用，注册后 5 分钟内可完成首次解析调用

<!-- page 8 -->
# 集成能力

- 提供 RESTful API 与 Python SDK，单行调用即可完成文档解析
- 兼容主流知识库与 RAG 框架，已与 team KB、Dify、FastGPT 完成预集成

<!-- page 9 -->
# 性能规格

- 单实例支持每秒 20 页并发解析，集群部署可水平扩展至每日千万页级吞吐
- 支持 PDF、DOCX、PPTX、XLSX、图片等 30 余种文档格式的统一解析入口
